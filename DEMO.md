# CareContinuum Agent — Demo Flow

1. Run `START.bat`.
2. Open `http://127.0.0.1:5000`.
3. Click **Run Care Agent**.
4. Confirm **Plan ready** with 3 proposed actions.
5. Click **Approve & execute**.
6. Show **Verified** and **Closed loop = 1**.

The server uses only Python's standard library. No `pip install` is required.
